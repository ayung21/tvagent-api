revisi jalankan pm2 resurrect via widget terusan langkah awal

1. buka f-droid
2. search "termux" dan install termux:widget
3. mkdir -p .shortcuts
4. nano .shortcuts/start
5. (isi sesuai file atau copy kan file start di dalam .shortcuts)
6. chmod +x .shortcuts/start

Pasang di Home Screen:
    - Kembali ke layar utama HP/TV.
    - Tekan tahan layar kosong -> Pilih Widgets.
    - Cari Termux:Widget.
    - Pilih widget tersebut, nanti akan muncul daftar skrip yang ada di folder .shortcuts.
    - Pilih start
    - jika widget belum mendapat izin (setting - apps - special app access - display over other apps - pilih termux) (tv)
    - jika widget belum mendapat izin (setting - apps - muncul di atas - pilih termux)
    - Instal aplikasi Button Mapper dari Play Store di TV.
    - Buka aplikasi, berikan izin Accessibility (Aksesibilitas).
    - Pilih tombol yang mau dikorbankan (misal: Tombol Biru atau Long Press tombol Back).
    - Pilih Customize -> Single Tap (atau Long Press).
    - Pilih Actions -> Shortcuts (Pintasan).
    - Cari Termux:Widget.
    - Pilih script jalankan-pm2.
